# ระบบบันทึกและติดตามพฤติกรรมนักเรียน (Student Behavior Tracking System)

ระบบบันทึกและติดตามพฤติกรรมนักเรียนสำหรับครู/อาจารย์ เพื่อส่งเสริมพฤติกรรมที่ดีและช่วยเหลือดูแลนักเรียนอย่างเป็นระบบ พัฒนาโดยใช้ **Google Apps Script** และมีระบบฐานข้อมูลผ่าน **Google Sheets**

## คุณสมบัติเด่น (Key Features)
- 📊 **Dashboard:** แสดงจำนวนนักเรียน, สรุปสถิติความประพฤติ (ดี/ผิดระเบียบ) ย้อนหลัง 7 วัน ด้วยกราฟแท่ง (Chart.js), รายชื่อนักเรียนดีเด่น และตารางแสดงประวัติล่าสุด 5 รายการ
- ✏️ **Data Management:** ระบบจัดการข้อมูลนักเรียน (เพิ่ม/ลบ/แก้ไข/ค้นหา), การจัดการบัญชีผู้ใช้ครูผู้ใช้งาน
- 📝 **Behavior Logging:** บันทึกพฤติกรรมดี/ผิดระเบียบ (เบา, ปานกลาง, ร้ายแรง) พร้อมการให้คะแนนอัปเดตคะแนนรวมนักเรียนอัตโนมัติ (-5, -10, -20, +5, +10, +20)
- 📄 **Individual Reporting:** ระบบค้นหาและดูรายงานประวัติพฤติกรรมรายบุคคล และสั่งพิมพ์ออกกระดาษหรือ PDF ได้ทันที
- 🔐 **Security & UI:** ล็อกอินเข้าใช้งานด้วยบัญชีครู, หน้าต่างแจ้งเตือนสวยงามด้วย SweetAlert2, ออกแบบโดยใช้สไตล์ AdminLTE + Tailwind CSS (Responsive รองรับการใช้งานผ่านมือถือ)

## วิธีการนำไปใช้งานจริง (Setup Instruction)

### 1. การเตรียมระบบ Google Sheets
สร้าง Google Sheets ใหม่ขึ้นมา (ไม่ต้องใส่ข้อมูลหรือสร้างตารางใดๆ ล่วงหน้า):
- **ระบบจะสร้างแท็บ (Tabs) ทั้งหมดให้โดยอัตโนมัติ** ได้แก่ `Users`, `Students`, และ `Behaviors`
- **ระบบจะสร้างหัวตาราง (Headers) ของแต่ละแท็บให้โดยอัตโนมัติ**
- **ระบบจะสร้างบัญชีผู้ใช้เริ่มต้น (admin / admin)** ในแท็บ `Users` ให้โดยอัตโนมัติเพื่อให้สามารถล็อกอินใช้งานได้ในครั้งแรกทันที
*(คุณเพียงแค่สร้าง Google Sheets เปล่าๆ ขึ้นมาเท่านั้น)*

### 2. การติดตั้งโค้ดบน Google Apps Script
1. ในหน้า Google Sheets ที่คุณสร้าง ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกให้หมด จากนั้นนำโค้ดในไฟล์ [Code.gs](./Code.gs) ไปวางแทน
3. กดปุ่ม **+ (เพิ่มไฟล์)** ทางด้านซ้าย > เลือก **HTML** ตั้งชื่อไฟล์ว่า `Index` และนำโค้ดจาก [index.html](./index.html) ไปวาง
4. กดเพิ่มไฟล์ **HTML** ตั้งชื่อไฟล์ว่า `CSS` และนำโค้ดจาก [CSS.html](./CSS.html) ไปวาง
5. กดเพิ่มไฟล์ **HTML** ตั้งชื่อไฟล์ว่า `JavaScript` และนำโค้ดจาก [JavaScript.html](./JavaScript.html) ไปวาง

### 3. การเปิดใช้งาน Web App (Deploy)
1. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** ที่มุมบนขวา > เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกเลือกรูปเฟืองเลือกเป็น **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **เรียกใช้งานในฐานะ (Execute as):** ตัวฉัน (Me - อีเมลของคุณ)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **การทำให้ใช้งานได้ (Deploy)**
5. กดยอมรับสิทธิ์การใช้งาน (Authorize Access) ให้เรียบร้อยตามขั้นตอนของ Google
6. คัดลอกลิงก์ Web App URL ที่ได้เพื่อเปิดใช้งานระบบ

```bash
├── Index.html          # โครงหน้าต่างหลักของระบบ (HTML)

└── test_local.html     # ไฟล์รวมโค้ดสำหรับการเปิดทดสอบแบบออฟไลน์
```
